--- Network 6  Comment: Zero adjustment has to be performed prior to this linearity adjustment procedure.

1. Specify how many linearity adjustment points to be performed by loading interger 0, 1, 2 or 3 into LinearityRange (0 for 2 points, 1 for 3 points, 2 for 4 points and 3 for 5 points). Please be noted that the earlier performed zero adjustment point is considered as the first adjustment point (Point #1).

2. Configure all the adjustment weight values into xLow, Low, Middle and High (for e.g. 5-point adjustment requires all 4 weights: High, Middle, Low and xLow; 3-point requires High and Middle; 2-point only requies High as the 1st point is the zero reference)

3. Make sure the Linearity Range parameter and all the adjustment weight values are configured correctly before starting the adjustment process. Invalid or incomplete parameters will cause the Function Block to turn on the Error output bit.

4. Trigger ON  Input Start bit to start the span adjustment. This Start bit will be turned off by the Function Block upon completion/ cancellation or error condition. 

5. Once started, CurrentPoint shows the current linearity point to be adjusted; CurrentWeight shows current adjustment weight to be loaded onto the scale. The LoadWeight output bit will be set ON to request for new adjustment weight. 

6. After loading the new adjustment weight, acknowledge this by triggering the ConfirmWeight parameter (boolean) ON. The Function Block will then proceed to the next adjustment point and turn off this ConfirmWeight bit.

7. Output bit - Process signifies that the adjustment of current point is in process.

8. Input Parameter Bit Cancel is used to cancel/ abort the adjustment process | Title: Span Adjustment

--- Network 7  Comment: CalFree is a method of analog scale adjustment without using test weights. It takes the factory calibrated load cell Rated Output (mV/ Vexc.) and user defined scale capacity to build a linear loading curve.
This method is usually applied to huge capacity scales in which calibration with test weights or other material is not feasible at all. 

For Powercell scale, please use the CalFree+ Function Block instead.

1. Write in.. 
(a) CalFree Scale Capacity (Index 0x401A), 
(b) CalFree Scale unit (Index 0x401C, Decimal 0 - gram; Decimal 1 - KG; Decimal 2 - Pounds) and 
(c) Load Cells' averaged Rated Output (Index 0x401D, in mV/V)
**Make sure the transmitter's scale capacity has already been configured to the same value as CalFree Capacity prior to this CalFree adjustment.

2. Trigger Input bit Start for CalFree adjustment (Index 0x401A)

3. Output bit Done will be turned ON after successful completion of the process
Error output bit will be turned ON if there is an error during the adjustment process | Title: CalFree Adjustment

--- Network 8  Comment: Use this Function Block to read one alibi record. 
1. Set the alibi transaction number to be read.

4. the Alibi_Array structure data format is as below:

For Base, RateControl, Tank Vessel:

Float32:  Net Weight;                           =>Byte28-31
Float32:  Tare Weight;                         =>Byte32-35
Byte:     Tare Mode;                              =>Byte36
Byte:     Unit;                                          =>Byte37
Byte[6]:  Not Used;                              =>Byte38-43
} | Title: Alibi Record Read
