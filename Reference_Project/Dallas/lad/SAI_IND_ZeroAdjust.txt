--- Network 2  Comment: AdjustStep:

10. Trigger the zero adjustment acyclic command (1-Byte; Index = 16#400B). 

20: Read the adjustment status (2-Byte; Index = 16#4007). Status "2047" is in process; Status "0" means adjustment is completed.
Upon completion of adjustment, the input bit START will be turned off by the Function Block.
Output bit DONE will be turned ON. If there is an error during the adjustment, ERROR bit will be turned ON. | Title: Sequence
   parts: Coil, Contact, Eq, Move, Ne, PContact, RCoil, RDREC, SCoil, WRREC
   operands: #Activate, #AdjustStep, #Zero_RECORD, #WRREC_Zero.DONE, #WRREC_Zero.REQ, #ID, #WRREC_Zero.BUSY, #WRREC_Zero.ERROR, #WRREC_Zero.STATUS, #Static02, #RDREC_Status.BUSY, #RDREC_Status.REQ, #Status_RECORD, #RDREC_Status.VALID, #RDREC_Status.ERROR, #RDREC_Status.STATUS, #Process, #Done, #Error, #Start
