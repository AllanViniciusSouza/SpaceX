--- Network 2  Comment: CalFree adjustment steps:

1. Switch on Input bit Start

2. Write in (a) Scale Capacity (Index 0x401A), (b) Scale unit (Index 0x401C, Decimal 0 - gram; Decimal 1 - KG; Decimal 2 - Pounds) and (c) Load Cells' averaged Rated Output (Index 0x401D, in mV/V)

3. Start CalFree adjustment (Index 0x401A)

4. Continuously read in adjustment status (Index 0x4007)

5. Output bit Done will be turned ON after completion of the process | Title: Sequence
